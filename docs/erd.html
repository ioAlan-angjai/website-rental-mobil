🔑 Hubungan Relasi Utama
  • User ➔ Booking 1 : Many (SetNull)
  • Car ➔ Booking 1 : Many (Restrict)
  • Booking ➔ Invoice 1 : 1 (Cascade)
  • Booking ➔ Payment 1 : Many (Cascade)
  • User ➔ Chat / Message 1 : Many (Cascade)
  • Chat ➔ ChatMessage 1 : Many (Cascade)
⚙️ Status Transaksi (Booking Status)
  • Awal Pemesanan PENDING / WAITING_DP
  • DP Diverifikasi DP_CONFIRMED
  • Mobil Digunakan IN_PROGRESS
  • Mobil Selesai Digunakan WAITING_RETURN
  • Pelunasan / Denda WAITING_PAYMENT
  • Selesai Seluruhnya COMPLETED

  • Metode Manual Transfer Bank BCA/BNI/Mandiri
  • Status Pembayaran PENDING | VERIFIED | REJECTED
